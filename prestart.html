Pre-Startup Procedure

The pre-startup procedure is a very crucial part of operating the reactor. It ensures that when the startup is complete, there will be no additional tasks required such as enabling cooling valves or setting temperatures for specfic systems. This procedure allows the operator to run the reactor with less stress and more comfort.

Pre-Startup Checklist

Electrical Systems

  1. Head to the electrical control room and disable the emergency power line and enable the main power line.
  2. Turn all the switches next to the main power line lever

Reactor Systems

  1. Turn on the display power button
  2. Check for any faulty systems or malfunctions.
  3. Ensure all safety systems are functioning correctly.
  4. If necessary, perform any required maintenance or repairs.
  5. Make sure all pipes are connected properly.
  6. Set the steam bypass valve on the turbines to 40%.
  7. Turn off the OCCS (Offline Core Cooling Systems).

Proceed to Reactor Startup Once Complete
